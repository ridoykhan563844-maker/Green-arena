CRASH DEMO Android app (virtual coins only)

Open this folder in Android Studio:
1. Install Android Studio.
2. Choose Open and select this CrashDemoAndroid folder.
3. Let Gradle sync complete.
4. Connect an Android phone with Developer Options + USB debugging enabled, or start an emulator.
5. Press Run.

To build an APK:
Build > Build Bundle(s) / APK(s) > Build APK(s)

The app is a local demo only. It uses virtual coins, has no real-money deposits/withdrawals,
no account system, and no server. The randomly generated round outcome is for demonstration
and is not secure or suitable for real-money wagering.
